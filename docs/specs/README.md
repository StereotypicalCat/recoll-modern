# Specs

Approved specifications from the superpowers brainstorming workflow. Nothing non-trivial gets
implemented without one.

- Naming: `NNN-short-slug.md`, zero-padded, sequential.
- A spec states **what** and **why**, plus acceptance criteria. Not **how**.
- Front matter: `status: draft | approved | implemented | superseded`, and a link to its plan.
- Never delete an implemented spec; it is the record of intent.

This path overrides the superpowers default (`docs/superpowers/specs/`) — see `AGENTS.md`.
